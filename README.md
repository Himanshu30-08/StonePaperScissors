Stone Paper Scissors is a simple and interactive game application based on the classic hand game played between a user and the computer. The project is designed to demonstrate fundamental programming concepts, user interaction handling, game logic implementation, and random number generation through a clean and responsive interface.

The application allows users to choose between Stone, Paper, or Scissors, while the computer automatically generates a random choice. The winner is decided based on standard game rules:

Stone beats Scissors
Scissors beats Paper
Paper beats Stone

The project focuses on improving logical thinking, event handling, and front-end development skills while providing an engaging gaming experience.
